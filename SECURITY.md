# Security Policy

## Supported scope

This repository is a deterministic demo and reference implementation. Security issues in the codebase, dependency configuration, authentication flows, authorization logic, or data-handling behavior are in scope.

## Reporting a vulnerability

Please do not open a public issue for suspected vulnerabilities.

Use one of these channels instead:

- GitHub Security Advisories for the repository, if enabled.
- Email: `husnainbinmunawar@gmail.com`

Please include:

- A clear description of the issue.
- Steps to reproduce.
- Expected impact.
- Any logs, screenshots, or proof-of-concept details that help validate the report.

## Response expectations

- Good-faith reports will be acknowledged as quickly as possible.
- Fix timelines depend on severity and reproducibility.
- Public disclosure should wait until a fix or mitigation is available.

## Demo-specific note

The project includes simulated integrations and seeded demo accounts. Those demo credentials are intentionally scoped to local/sample usage and are not valid for any external service.
