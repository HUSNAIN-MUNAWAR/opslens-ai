# Storyboard: OpsLens decision loop

1. **Seed** — load deterministic synthetic organizations, operational records, quality issues, and policies.
2. **Plan** — classify a stockout question against certified metrics and approved tables.
3. **Guard** — validate read-only SQL, tenant scope, complexity, and row limits before execution.
4. **Evidence** — package rows, data-quality notices, confidence, and audit-ready trace metadata.
5. **Simulate** — show forecast and scenario effects with an explicit no-mutation assurance.
6. **Approve** — complete Operations Manager and Organization Admin approval steps for the simulated recommendation.

The reel communicates model/reference behavior and governance, not live business performance.
